Privacy Policy

Channel Stats · Last updated: October 22, 2026

Channel Stats ("the tool") is a personal tool that lets its owner view data about their own YouTube channel, and upload their own videos to it, inside the Claude Desktop app. This policy explains what data the tool accesses and how it is handled.

Data the tool accesses

Only after the channel owner signs in with Google and grants permission, the tool reads:

  • Channel information (name, subscriber count, total views, list of uploaded videos and their public statistics) through the YouTube Data API v3, scope youtube.readonly.
  • YouTube Analytics reports for the owner's channel (views, watch time, audience and traffic breakdowns) through the YouTube Analytics API, scope yt-analytics.readonly.
  • Estimated revenue and ad performance reports for the owner's channel, scope yt-analytics-monetary.readonly.
  • Permission to upload videos to the owner's channel through the YouTube Data API v3, scope youtube.upload. The tool uses it only when the owner asks it to upload a specific video file, and sends that file with the title, description, tags and optional thumbnail the owner has approved. Uploads are private unless the owner chooses otherwise.

Apart from uploads the owner asks for, all access is read-only. The tool cannot edit or delete existing videos, playlists, comments or channel settings.

How the data is used

Data is used only to show statistics and reports to the channel owner and to upload the videos the owner chooses. It is not used for advertising, profiling or any other purpose.

Storage and sharing

  • The Google sign-in token is stored only on the owner's own computer (folder .youtube-channel-stats-mcp in the home folder). The tool has no server of its own.
  • Reports are shown to the owner in Claude Desktop, an AI assistant made by Anthropic. When the owner asks Claude about their channel, the requested data is processed by that service as part of the owner's own conversation, under Anthropic's terms and privacy policy.
  • CSV exports, when requested by the owner, are saved only to a folder on the owner's computer.
  • Video and thumbnail files chosen for upload are read from the owner's computer and sent only to YouTube. The tool keeps no copy of them.
  • Data is never sold, and is not shared with anyone else.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access and data

Access can be revoked at any time from the Google security settings page. Deleting the .youtube-channel-stats-mcp folder removes the stored sign-in from the computer.

Contact

Questions about this policy can be sent to the support email address shown on this app's Google sign-in screen.
